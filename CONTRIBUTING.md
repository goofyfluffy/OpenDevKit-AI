# Contributing

OpenDevKit AI welcomes constructive contributions.

1. Open an issue describing a bug or proposed enhancement.
2. Fork the repository and create a focused feature branch.
3. Add tests for new analyzer behavior.
4. Run `python -m unittest discover -s tests -v`.
5. Submit a pull request with a concise explanation and example input/output.

Do not include secrets or private source code in issues. Be respectful. The project is an early prototype and review time may vary.
